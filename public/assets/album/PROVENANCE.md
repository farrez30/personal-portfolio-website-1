# Asal seni album CD

Semua berkas di folder ini **buatan AI**: Google Flow, model Nano Banana 2.1, akun Google AI Pro Farrez, 5 November 2026, satu project Flow (`Nov 05 - 13:43`). Biaya 0 kredit Flow (panel menulis "Generating will use 0 credits"; saldo 900 sebelum dan sesudah). Tiap prompt dibuat 2 variasi; yang terpilih tertulis di kolom Varian. SynthID dari Google tetap tertanam; watermark terlihat mati.

Orang di gambar fiktif. Tidak ada wajah klien, tidak ada teks atau klaim tercetak. Prompt lengkap per berkas ada di [docs/seni-cd/prompt.json](../../../docs/seni-cd/prompt.json) (cocokkan `slug` dan `berkas`); genre dan alasannya di [docs/genre-cd.md](../../../docs/genre-cd.md).

Pengolahan: JPEG asli Flow (1024x1024, sisipan belakang 1200x896) disimpan dengan kedua variasinya di `D:\downloads\claude\2026-11-05-flow-album-cd\`. Diubah dengan ffmpeg ke WebP: sampul dan label 1024 px q82, belakang 1200 px q80, halaman buklet 768 px q78.

Revisi: prompt YiheeCam (sampul, belakang, buklet 2 dan 6) diubah setelah Farrez mengoreksi bahwa kamera aksinya dipasang di chin mount helm, bukan di atas helm. Gambar versi lama tidak dipakai.

Sampul berjudul (`sampul-judul.webp`): sampul terpilih diedit di layar edit Flow (Nano Banana 2.1, 0 kredit, 5 Nov 2026), dengan judul berbahasa Indonesia digambar oleh model. Prompt per sampul ada di [docs/seni-cd/prompt-judul.json](../../../docs/seni-cd/prompt-judul.json). Ejaan 10 dari 10 dicek manual dari gambar aslinya. Farrez memilih versi ini untuk semua sampul depan. Asli JPEG ada di `D:\downloads\claude\2026-11-05-flow-album-cd\_judul-ai\`, diubah ke WebP 1024 px q82.

Logo proyek (`logo.svg`) bukan buatan AI: disalin apa adanya dari repo proyek milik Farrez sendiri (FiFoFun `public/icon.svg`, Jeda `src/app/icon.svg`, AkarKita `app/icon.svg`, d-day `dashboard/src/app/icon.svg` ditambah width/height 64, NDS-ETL `web/app/icon.svg`, Coderoach `public/brand/coderoach_logo.svg`) pada 5 Nov 2026. Semuanya SVG tanpa skrip dan tanpa rujukan luar.
